## 三、六者角色能力矩阵

| 角色 | slug | 对应岗位 | 核心能力 | 绑定端点组 |
| --- | --- | --- | --- | --- |
| 医者 | `role-healer` | 临床医师 / 带教老师 | 辨证推理 + 方剂推荐 + **师带徒** + 医圣成长 | `/consult` `/teach` `/analyze-case` `/kg/*` `/diag` `/bianzheng` |
| 患者 | `role-patient` | 就诊患者 / 家属 | 症状自查 + 导诊 + 用药白话说明 | `/patients/*` |
| 药者 | `role-pharmacist` | 药剂师 / 药企 | 处方审核 + 相互作用 + 替代建议 + 饮片溯源 | `/pharmacists/*` |
| 械者 | `role-device` | 设备科 / 影像科 | 维护 + 影像辅助 + 采购论证 + 质控追溯 | `/devices/*` |
| 规者 | `role-regulator` | 院办 / 质控 / 后勤 | 质控 + 排班 + 资源利用 + 应急调度 | `/regulators/*` |
| 法者 | `role-legal` | 医事律师 / 法务 | 风险 + 知情同意 + 法规 + 纠纷预防 + 医保合规 | `/legals/*` |

> **体系要点**：师者**不独立成角**——年长医师自然带教年轻医生，师者功能融入医者 Agent。医者是六者核心枢纽。
>
> 除 6 个专职角色技能外，另有 8 个学科/管理技能也归属角色（如 `tcm-toxicology` → 药者、`tcm-ophthalmology` → 医者）。

**完整逐学科对照与缺口清单见 [`docs/06-学科覆盖矩阵.md`](06-学科覆盖矩阵.md)**（生成物，随技能增减自动更新）。

### 差距分析结论

- **平台能力层（D07 + 六者 + 医圣成长）已完整覆盖**——这是与 tcmP 平台强相关、不可替代的部分。
- **学科同步层已从骨架推进到「主体成型」**（42 → 72 技能）。
- 扩展路径遵循**参数化原则**：一个 `tcm-basic-theory` 通过 `textbookCode` / `chapter` / `knowledgePoint` 覆盖整个中基课程；**只有当某学科的「教学工作流形态」不同于既有技能时，才新增技能**。
- v0.5.0 目标：覆盖 ≥ 80%，技能数 ≥ 90。
