# 命名与编码规范

> 版本 v0.2.0 ｜ 本规范约束 **spec 内容** 与 **生成物形态**。违反规范的提交会被 `npm run build` / `npm run validate` / `npm run check:docs` 直接拒绝。

---

## 一、目录与文件布局

```
skills/<category-slug>/<skill-slug>/SKILL.md
       └── 分类目录           └── 技能目录（必须等于 slug）  └── 固定文件名
```

| 规则 | 说明 |
| --- | --- |
| 分类目录 = `CATEGORIES[].slug` | 只允许 spec 中登记的分类 |
| 技能目录 = 技能 slug | 目录名与 slug 不一致 → validate 失败 |
| 文件名固定为 `SKILL.md` | 大小写敏感，必须全大写 |
| 一个技能目录只放一个 SKILL.md | 附加资源放 `references/` `scripts/` `assets/` 子目录 |

---

## 二、slug 命名规则

```
^[a-z0-9]+(-[a-z0-9]+)*$        ← kebab-case，纯小写
```

**命名公式**：

| 技能类型 | 公式 | 示例 |
| --- | --- | --- |
| 学科同步类 | `tcm-<学科英文短名>` | `tcm-basic-theory`、`tcm-formulas`、`tcm-tuina` |
| 平台能力类 | `tcm-<能力域>-<能力>` | `tcm-dsu-retrieval`、`tcm-kg-query`、`tcm-icd11-coding` |
| 六者角色类 | `role-<角色英文>` | `role-healer`、`role-pharmacist`、`role-legal` |
| 医圣成长类 | `sage-<行为>` | `sage-mentorship`、`sage-growth-path` |
| 通用学习类 | `tcm-<学习动作>` | `tcm-study-plan`、`tcm-mistake-review` |
| 备考类 | `tcm-<考试英文>-exam` | `tcm-licensed-physician-exam` |

**禁止**：
- 中文 slug、拼音 slug（`tcm-zhongji` ❌）
- 把年级 / 册别 / 章节 / 难度塞进 slug（`tcm-basic-theory-ch3-hard` ❌）——这些是**参数**，不是技能维度
- 缩写含糊（`tcm-misc`、`tcm-utils` ❌）

## 三之二、四级编码（篇·章·节·目）

对齐 tcmP 教材目录的**四级编码约定**：编码纯数字分列，横向读即完整编码 `篇.章.节.目`。

| 级 | 名称 | 取值 | 由谁决定 |
| :-: | --- | --- | --- |
| L1 篇 | 分类 | 12 个分类 | `CATEGORIES` 的数组顺序 |
| L2 章 | 主学科 | `subjects[0]` | spec 中技能的学科声明顺序 |
| L3 节 | 能力族 | 9 个能力族 + 「综合能力」兜底 | `CAPABILITY_FAMILIES` 的匹配顺序（首命中） |
| L4 目 | 技能 | skill | spec 中同章同节技能的书写顺序 |

**示例**：

```
篇 1  中医基础与经典
 章 1  中医基础理论
   节 1  概念与记忆
     目 1  1.1.1.1  tcm-basic-theory   中医基础理论 Skill
```

**规则**：

- 四级编码**由生成器推导**，spec 中**不写** `library_code`；手写会被 `build` 覆盖。
- 一个技能只有一个四级编码（单值定位）。多学科 / 多能力的其余项保留为检索标签。
- 改名 / 调序会改变编码 —— 属于**破坏性变更**，须在 CHANGELOG 标明。
- 每个 `SKILL.md` 必须含 `## 四级目录定位 / Library Position` 章节，且正文出现其编码（`validate` 强校验）。

## 五、SKILL.md frontmatter 字段定义

```yaml
---
name: "<slug>"                 # 必填，必须等于目录名
description: "<summary>"       # 必填，一句话；平台绑定技能追加「依赖 tcmP 平台接口，离线不可用。」
version: "0.1.0"               # 必填，等于 PACK.version（不单独版本化）
author: qhzytcm                # 必填，validate 强校验
license: MIT                   # 必填
platforms: [windows, linux, macos]
metadata:
  hermes:
    tags: []                   # 检索关键词
    source: agent-tcmedu-skills  # 必填，validate 强校验
    category: "<分类 slug>"
    domain: "<D01..D08 | 平台 | ->"
    library_code: "1.2.1.1"       # ← 生成物：四级编码（篇.章.节.目），勿手写
    stages: []                 # 学段：本科 / 硕士 / 博士 / 规培 / 继续教育
    subjects: []               # 学科名（与教材名对齐）
    abilities: []              # 能力项
    scenarios: []              # 使用场景
    roles: []                  # 六者：healer/patient/pharmacist/device/regulator/legal
    textbook_codes: []         # 教材号（必须真实存在）
    level_gate: ""             # 医圣成长门禁（仅成长/角色类技能）
    platform_apis: []          # 必须是 PLATFORM_APIS 中已登记的键
    quality_tier: "curated"
    standalone_support: "supported | needs_user_input | needs_platform"
    public_release: "recommended"
    export_mode: "installable"
    release_channel: "recommended"
    requires_tools: []
    requires_data: []
---
```

| 字段 | 取值 | 校验方式 |
| --- | --- | --- |
| `platform_apis` | 只能填 `PLATFORM_APIS` 的键 | `build-pack` 完整性检查，未登记直接抛错 |
| `textbook_codes` | 主仓真实教材号 | 人工 + 代码评审 |
| `standalone_support` | `needs_platform` 当且仅当 `platform_apis` 非空 | `validate` 抽查 |
| `source` / `author` | 固定值 | `validate` 强校验 |
| `roles` | 六者枚举 | 代码评审 |

## 六、标准章节结构

每个 `SKILL.md` 的正文**必须**包含以下章节（顺序固定）：

| # | 章节 | 是否必填 | 说明 |
| :-: | --- | :-: | --- |
| 1 | `# 标题` + 导语 | ✅ | 导语 = spec 的 `problem` |
| 2 | `## 最适合 / Best For` | ✅ | ≥ 2 条 |
| 3 | `## 不适合 / Not For` | ✅ | ≥ 1 条（边界比能力更重要） |
| 4 | `## 使用前请准备 / Inputs` | ✅ | 用户需提供的信息 |
| 5 | `## 推荐工作流 / Recommended Workflow` | ✅ | 有序步骤，≥ 4 步 |
| 6 | `## 产出 / Outputs` | ✅ | 产物清单 |
| 7 | `## 与 tcmP 平台的对接 / Platform Binding` | ✅ | **本亚项目独有**；含接口表 + 教材/角色/门禁/离线性 |
| 8 | `## 参数 / Parameters` | ✅ | 参数化维度表 |
| 9 | `## 质量门禁 / Quality Gate` | ✅ | 4 条固定门禁 |

`validate.mjs` 强校验第 7、9 章的**标题原文**存在。

## 七、参数维度

**原则**：学段、年级、册别、单元、课时、知识点、难度、题量**一律作为参数传入**，不拆成独立技能。

| 参数 | 值域 | 缺省行为 |
| --- | --- | --- |
| `discipline` | `D{NN}-S{NN}` | 按技能绑定的教材推断 |
| `textbookCode` | 教材号 | 按技能 `textbookCodes` |
| `chapter` | 章 / 节 | 选取该场景高频基础内容 |
| `knowledgePoint` | 知识点 / DSU 编号 | 同上 |
| `scenario` | 预习 / 巩固 / 复习 / 演练 / 备考 / 培训 | 取技能 `scenarios[0]` |
| `difficulty` | 基础 / 提高 / 综合 | 基础 50% + 提高 40% + 综合 10% |
| `itemCount` | 正整数 | 8–12 道 或 30 分钟任务 |
